# 🌤️ Aplicación de Clima - React

Esta es una aplicación web desarrollada con **React** y **Vite** que permite consultar el estado del clima de una ciudad en tiempo real.

## 🚀 Funcionalidades
- Búsqueda de clima por ciudad.
- Visualización de temperatura actual.
- visualizacion de foto con el estado del clima 
- Interfaz rápida y responsiva.
